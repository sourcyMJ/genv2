Политика конфиденциальности GenV2

GenV2 — личное приложение одного человека (владельца). Других пользователей нет.

  • Какие данные: данные носимого устройства владельца из Google Health API (шаги, сон, пульс, вариабельность пульса, частота дыхания, насыщение кислородом, вес) и записи, которые владелец делает сам.
  • Зачем: только для личного дневника здоровья владельца.
  • Хранение: на собственном сервере владельца и в его резервных копиях.
  • Передача третьим лицам: не передаются, не продаются и не используются для рекламы.
  • Удаление: владелец может в любой момент отозвать доступ в настройках аккаунта Google и удалить данные.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English). GenV2 is a single-user personal app. It reads only its owner's own Google Health API data (activity, sleep, heart rate, HRV, respiratory rate, SpO2, weight) solely to keep the owner's personal health journal. Data is stored on the owner's own server and backups, is never shared with or sold to third parties, and is not used for advertising. The owner can revoke access in Google Account settings at any time. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
