GenV2

GenV2 — личный дневник здоровья для одного человека, его владельца. Приложение не предназначено для других пользователей.

С разрешения владельца оно читает его собственные данные носимого устройства (активность, сон, пульс) через Google Health API и сохраняет их в личный дневник.

Политика конфиденциальности

GenV2 is a personal, single-user health journal. With the owner's consent it reads the owner's own wearable data (activity, sleep, heart rate) via the Google Health API. It is not offered to other users. Privacy policy.
